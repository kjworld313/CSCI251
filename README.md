# Software Design Course Portfolio

***

## Directory Information
The directory 'individual_projects' contains two directories: int_vector and bank_app. The int_vector directory contains a self-implemented IntVector library. The bank_app directory includes a banking software with bank account, saving account, and checking account classes.

## Important Notes
These projects require C++11 or higher to compile.

## Program Instructions
In order to run int_vector program, use the 'g++ IntVector.cpp main.cpp' in the terminal. For bank_app, use 'g++ main.cpp BankAccount.cpp CheckingAccount.cpp SavingAccount.cpp Utils.cpp'
